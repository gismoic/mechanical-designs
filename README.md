# neo-Intake
<img width="494" height="351" alt="image" src="https://github.com/user-attachments/assets/27e8a9ed-2437-4af5-90c4-77a601582a63" />

This is my floating intake design for the university division of the VEX Robotics Competition 2026-2027. The operating principle of this mechanism is that the
arms sit on 1/2'' OD bearings and rotate on bolts as the axle with the flex wheels pulls in game objects. The external gear reduction allows for a fast-moving intake
with only a single 11W motor. This design is planned to be incorporated into our 18x18x18in robot.
